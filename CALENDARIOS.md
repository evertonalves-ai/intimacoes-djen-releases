# Calendários cadastrados

Tribunais e anos para os quais o Intimações DJEN conhece os dias sem expediente fixados pelo próprio tribunal (cláusula 3.2 dos Termos de Uso). Para os demais, o programa usa os feriados nacionais e estaduais e mostra no cartão o aviso de que o calendário daquele tribunal não está cadastrado.

Cada calendário é transcrito do ato oficial do tribunal. A lista é gerada a partir dos próprios arquivos que o programa usa.
